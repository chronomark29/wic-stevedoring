Bagian 1

Apa yang Anda terima

Website ini hanya sebuah folder berisi berkas. Tidak ada WordPress, tidak ada database, tidak ada plugin, tidak ada biaya langganan. Folder ini diunggah ke hosting mana pun, lalu website langsung jalan. 

Wicstevedoring Site/
├── index.html               Beranda
├── tentang.html             Tentang Kami
├── layanan.html             Layanan + pencari muatan
├── proyek.html              Proyek / rekam jejak
├── galeri.html              Galeri foto
├── kontak.html              Kontak + formulir penawaran
├── favicon.svg              Ikon kecil di tab browser
├── robots.txt               Instruksi untuk mesin pencari
├── sitemap.xml              Peta situs untuk Google

Bagian 2

Cara mengunduh dari GitHub

Seluruh kode website tersimpan di GitHub — layanan penyimpanan kode di internet. Repo ini terbuka untuk umum, jadi Anda tidak perlu punya akun atau login. Alamatnya:

github.com/chronomark29/wic-stevedoring

Alamat di atas bisa langsung diklik. Kalau membaca versi cetak, ketik apa adanya — tanpa https:// pun tetap terbuka.

Cara A — Unduh ZIP (paling gampang)

  1. Buka alamat di atas lewat browser.
  2. Cari tombol hijau bertuliskan Code, lalu klik.
  3. Pilih Download ZIP.
  4. Buka folder Downloads, klik kanan berkas ZIP tadi, pilih Extract All (Ekstrak Semua).
  5. Selesai. Hasil ekstraknya adalah folder website Anda.

Cara B — git clone (ikut menerima pembaruan)

Butuh aplikasi Git, gratis di git-scm.com/downloads. Setelah terpasang, buka Command Prompt lalu ketik: 

git clone https://github.com/chronomark29/wic-stevedoring.git

Kelebihannya: kalau nanti ada perbaikan, Anda cukup mengetik git pull untuk menarik versi terbaru — tidak perlu mengunduh ulang semuanya.

Tips penyimpanan Simpan folder hasil ekstrak di tempat yang mudah dicari, misalnya Documents\Website WIC. Hindari meninggalkannya di dalam folder Downloads, karena mudah terhapus saat bersih-bersih.

Bagian 3

Cara membuka di komputer sendiri

Sebelum diunggah ke internet, sebaiknya website dicoba dulu di komputer. Mengklik dua kali index.html memang menampilkan halaman, tetapi kalkulator estimasi, galeri, dan tombol ganti bahasa tidak akan berfungsi — browser memblokir sebagian fungsi bila berkas dibuka langsung dari hard disk.

Cara yang benar adalah menjalankan "server kecil" di komputer Anda sendiri:

  1. Buka folder website di File Explorer.
  2. Klik kolom alamat di bagian atas jendela, ketik cmd, tekan Enter. Muncul jendela hitam yang sudah berada di folder itu.
  3. Ketik perintah berikut, lalu tekan Enter: 
    python -m http.server 5211
  4. Buka browser, ketik alamat http://127.0.0.1:5211/
  5. Website tampil lengkap dengan semua fiturnya.
  6. Setelah selesai, kembali ke jendela hitam dan tekan Ctrl + C untuk menghentikannya.
Kalau muncul tulisan "python is not recognized" Artinya Python belum terpasang. Buka python.org/downloads, klik tombol kuning Download Python, jalankan berkasnya. Pada layar pertama pemasangan, centang kotak "Add Python to PATH" sebelum menekan Install. Setelah selesai, tutup dan buka ulang Command Prompt, lalu ulangi langkah 3.

Bagian 4

Cara memasang ke internet

Pilih satu di antara tiga cara berikut, sesuai hosting yang Anda pakai. Tidak ada yang perlu diatur pada ketiganya — tidak ada PHP, tidak ada Node, tidak ada database.

Pilihan 1 — cPanel (Niagahoster, Domainesia, Rumahweb)

  1. Masuk ke cPanel milik Anda.
  2. Buka menu File Manager.
  3. Masuk ke folder public_html.
  4. Hapus isi lama di dalamnya bila website versi lama masih ada di situ.
  5. Unggah seluruh isi folder website — bukan foldernya, melainkan isinya. index.html dan assets/ harus berada langsung di dalam public_html.
  6. Buka nama domain Anda di browser. Website sudah tayang.
Kesalahan yang paling sering terjadi Kalau index.html masuk ke dalam sub-folder — misalnya public_html/Wicstevedoring Site/index.html — website tidak akan muncul. Berkas index.html harus berada langsung di dalam public_html.

Bagian 4 · lanjutan

Dua pilihan hosting gratis

Pilihan 2 — Netlify (paling cepat)

  1. Buka app.netlify.com dan buat akun gratis.
  2. Setelah masuk, cari area bertuliskan "Drag and drop your site output folder here".
  3. Seret folder website dari File Explorer, jatuhkan ke area tersebut.
  4. Tunggu beberapa detik. Netlify langsung memberi alamat web.
  5. Nama domain sendiri dipasang lewat menu Domain settings.

Pilihan 3 — Vercel (otomatis mengikuti GitHub)

  1. Buka vercel.com dan masuk memakai akun GitHub.
  2. Klik Add New → Project.
  3. Pilih repository wic-stevedoring.
  4. Biarkan semua pengaturan apa adanya, lalu klik Deploy.
  5. Setiap perubahan yang disimpan ke GitHub membuat website otomatis diperbarui dalam waktu kurang dari satu menit.
Mana yang sebaiknya dipilih? Kalau Anda sudah punya hosting berbayar dan nama domain, pakai Pilihan 1. Kalau ingin website cepat tayang tanpa biaya, pakai Pilihan 3 — karena pembaruan berikutnya jadi otomatis, tidak perlu unggah ulang.

Bagian 5

Mengganti nomor telepon,
WhatsApp, dan email

Buka berkas assets/data/content.js memakai aplikasi teks apa pun. Notepad sudah cukup, tetapi Visual Studio Code jauh lebih nyaman — gratis di code.visualstudio.com.

Blok paling atas berisi data perusahaan:

WIC.company = {
  phone:    '+62 254 602424',
  phoneAlt: '+62 254 605604',
  whatsapp: '6281310121513',   // tanpa + dan tanpa spasi
  email:    'operation.wic@melati-group.com',
  ...
};

Ganti isi di dalam tanda kutip, simpan, selesai.

Jangan lupa bagian ini Nomor telepon dan email juga tertulis langsung di bagian atas (header) dan bawah (footer) ke-6 berkas HTML. Setelah mengubah content.js, cari juga tulisan 602424 dan operation.wic di seluruh berkas HTML, lalu ganti di sana.
Cara cepat mencarinya Di Visual Studio Code, tekan Ctrl + Shift + F untuk mencari sebuah kata di semua berkas sekaligus. Semua tempat yang memuat nomor lama akan langsung terdaftar, tinggal diganti satu per satu.

Bagian 6

Menambah foto galeri

  1. Simpan foto ke folder assets/img/gallery/
  2. Beri nama berurutan mengikuti yang sudah ada: g16.jpg, g17.jpg, dan seterusnya.
  3. Buka assets/data/content.js, cari bagian WIC.gallery, lalu tambahkan satu baris: 
    { f: 'g16.jpg', cat: 'operasi',
  cap: { id: 'Keterangan foto',
         en: 'Photo caption' } },
BagianArtinya
fNama berkas foto — harus persis sama dengan nama di folder
catKategori. Hanya boleh operasi, alat, kapal, atau tim
cap.idKeterangan foto Bahasa Indonesia
cap.enKeterangan foto Bahasa Inggris
Perkecil dulu ukuran fotonya Sebaiknya di bawah 500 KB supaya website tetap ringan dibuka dari HP. Foto dari kamera HP biasanya 3–5 MB, jadi perlu diperkecil. Bisa memakai squoosh.app — gratis, langsung di browser, tanpa memasang aplikasi.

Bagian 7

Menambah proyek
dan logo klien

Menambah proyek

  1. Simpan foto proyek ke assets/img/projects/
  2. Di content.js, cari WIC.projects, lalu salin satu blok yang sudah ada dan ubah isinya:
{
  id: 'nama-unik',
  img: 'assets/img/projects/foto-anda.png',
  client: 'PT. Nama Klien',
  figure: '30.000', unit: 'MT',
  title: { id: 'Judul Indonesia', en: 'English Title' },
  desc:  { id: 'Penjelasan singkat', en: 'Short description' },
  meta: [ { k: { id: 'Kapal', en: 'Vessel' },
            v: 'Mv. Nama Kapal' } ]
}

Isian id harus unik — tidak boleh sama dengan proyek lain.

Bagian 7b — Menambah logo klien

  1. Simpan berkas logo ke assets/img/partners/. Format PNG dengan latar transparan memberi hasil paling rapi.
  2. Di content.js, cari WIC.partners, tambahkan satu baris: 
    { n: 'Nama Perusahaan', f: 'namafile.png' },

Bagian 8

Menyetel angka
kalkulator estimasi

Kalkulator Estimasi Bongkar adalah fitur utama website ini. Calon pelanggan memilih komoditas, tonase, dan metode bongkar, lalu langsung melihat perkiraan produktivitas dan lama sandar.

Angka yang terpasang sekarang belum angka WIC Yang dipakai saat ini adalah rata-rata industri yang konservatif, bukan produktivitas WIC yang sebenarnya. Begitu diganti dengan angka Anda sendiri, alat ini menjadi benar-benar akurat — dan menjadi keunggulan yang tidak dimiliki PBM lain di Cilegon.

Di content.js, cari WIC.equipment:

// angka = MT per hari kerja efektif
{ id: 'ship-crane',  rate: [4000, 6000] },
{ id: 'shore-crane', rate: [6000, 10000] },
{ id: 'csu',         rate: [10000, 15000] },
{ id: 'bagged',      rate: [1500, 2500] },

Ubah pasangan angka [minimum, maksimum] sesuai produktivitas gang Anda.

Setiap komoditas juga punya factor — pengali yang menyesuaikan kecepatan bongkar menurut sifat muatan: batu bara 1.1 karena mengalir lancar, raw sugar 0.85 karena lebih lambat. Angka ini juga boleh disetel.

Website selalu menampilkan keterangan bahwa hasilnya bersifat perkiraan dan bukan penawaran resmi, sehingga aman dipakai sebagai alat percakapan awal dengan calon pelanggan.

Bagian 9

Mengubah tulisan
di halaman

Semua tulisan yang tampil di website tersimpan di satu berkas: assets/js/i18n.js. Isinya dua daftar — id: untuk Bahasa Indonesia dan en: untuk Bahasa Inggris.

Contoh satu baris tulisan:

'hero.title': 'Menggerakkan Muatan Anda,<br>
               Menguatkan Bisnis Anda',
Wajib diubah di dua tempat Setiap tulisan harus diubah di kedua daftar — id: dan en:. Kalau hanya salah satu, tulisan lama akan muncul kembali begitu pengunjung menekan tombol ganti bahasa.
Kalau tulisannya panjang atau banyak Pekerjaan ini yang paling mudah salah ketik — satu tanda kutip atau koma yang hilang membuat seluruh halaman jadi kosong putih. Untuk perubahan tulisan yang banyak, lebih aman dikerjakan lewat Kaelyth Studio (lihat halaman terakhir).

Bagian 10

Yang perlu dikonfirmasi
sebelum benar-benar live

Hal-hal berikut sengaja tidak dicantumkan di website karena belum bisa dipastikan kebenarannya. Website yang menawarkan jasa kepada Cargill dan Wilmar tidak boleh memuat klaim yang bisa dibantah.

HalAlasan belum dipakaiYang dibutuhkan
Sertifikasi ISO 9001:2015 Unggahan audit di Instagram menyebut Ratu Melati, perusahaan saudara, bukan WIC Nomor sertifikat atas nama WIC
Angka "2641" dari situs lama Muncul tanpa keterangan, artinya tidak diketahui Penjelasan artinya, misalnya jumlah kapal yang ditangani
Foto testimoni Situs lama memakai foto stok orang asing, bukan Didi Setiadi, Agustino, atau Diki Taufan Foto asli beserta izin pemakaian
Akun Instagram Footer lama menautkan @benua.group, sedangkan akun grup yang aktif @melati.group Konfirmasi akun mana yang benar
Titik peta Peta memakai pencarian alamat, bukan titik persis Tautan berbagi dari Google Maps
Sementara ini Testimoni ditampilkan sebagai kartu kutipan dengan logo perusahaan klien, tanpa foto orang. Begitu data di atas dikonfirmasi, semuanya bisa dipasang dan website menjadi lebih kuat lagi.

Bagian 12

Butuh update cepat
dan presisi?

Untuk perubahan rutin, pengerjaannya jauh lebih cepat dan hasilnya lebih rapi bila dikerjakan di Kaelyth Studio (Mark) — yang membangun website ini dan paling memahami strukturnya.

  • Menambah dan menata foto galeri
  • Memperbarui dokumentasi proyek dan rekam jejak
  • Mengganti angka kalkulator dan menambah logo klien
  • Membuat halaman baru atau bagian baru pada halaman lama
  • Memperbaiki tampilan yang berubah setelah diedit sendiri

Cukup kirimkan fotonya atau tulisannya. Perubahan langsung tayang, tanpa Anda perlu menyentuh kode sama sekali, dan tanpa risiko website rusak karena salah ketik satu tanda baca.
